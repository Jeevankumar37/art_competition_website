SAI SUCCESS LINE EDUCATION TRUST — ART COMPETITION WEBSITE

HOW TO RUN
1. Extract this folder.
2. Open index.html in a modern browser, or use VS Code Live Server.
3. The site is responsive and includes a mobile navigation menu and a registration enquiry dialog.

IMPORTANT
- The visual crops are taken from the image supplied as the design reference.
- The registration form is a front-end demo. It does not submit data to a server or save registrations.
- Before publishing, connect the form to a trusted backend or form service and add the organizer's privacy notice.
- Confirm event dates, age groups, contact numbers, rules and social media links before publishing.
- For deployment, upload the folder to GitHub Pages, Netlify, or an S3 static website/CloudFront setup.
